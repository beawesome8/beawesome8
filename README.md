## 🚀 Shipped Projects

### 🏆 [MatchCast](https://github.com/beawesome8/MatchCast)
Self-retraining FIFA World Cup 2026 match prediction pipeline. 84 automated retraining cycles, a champion/challenger promotion gate, correctly called the Final.
`FastAPI` `XGBoost` `Postgres` `Docker` `GitHub Actions`

### 🛡️ [PromptGuard](https://github.com/beawesome8/Prompt-Guard)
CI/CD safety gate for LLM prompt changes. Caught a 93.3% schema validity drop and a 122% cost increase; blocked 28 of 30 regression cases from shipping.
`Python` `Anthropic SDK` `Pydantic v2` `React/Vite`

### 📄 [DocuVet](https://github.com/beawesome8/DocuVet)
Multimodal document intake reviewer. Dual-OCR disagreement — not either engine's own confidence score — triggers vision fallback, catching a real misread a single-engine threshold would have missed.
`FastAPI` `Tesseract` `EasyOCR` `Claude Vision`

### 🔍 [CodeMark Red-Team Evaluation](https://github.com/beawesome8/codemark-redteam)
Adversarial evaluation of an AST-level code watermarking prototype. Reports an honest negative result: ordinary LLM code cleanup breaks the watermark, and a proposed fix from the underlying research didn't hold either.
`Python` `Claude API` `AST watermarking`

### 🧠 [BQ-Vertex-Analyst](https://github.com/beawesome8/BQ-Vertex-Analyst)
LangGraph agent for schema-aware BigQuery SQL generation on Vertex AI/Gemini, with a grounding gate that catches hallucinated table references. 100% on an 8-case golden set including adversarial paraphrase testing.
`LangGraph` `Vertex AI` `BigQuery` `Terraform`

### ❄️ [FreshCart Data Pipeline](https://github.com/beawesome8/FreshCart-Data-Pipeline)
Governed Snowflake ELT pipeline (Stage → Clean → Consumption). Data quality gate proven against a real injected bad row, not just asserted to work.
`Snowflake` `SQL` `GitHub Actions`
